# Foundations for Causal Inference

This repository is **private** and contains **all** the **lecture notes** for the course **Foundations for Causal Inference**, _Building the Mathematical and Statistical Foundations_.

Access to this content is restricted to enrolled students. All material is **privately owned, protected, and traceable**. Its use is strictly limited to enrolled students for the duration of the course.

The content is developed as a [Quarto Book](https://quarto.org), with native support for Markdown, LaTeX, code, and references.

The course is organized sequentially, starting with **Probability** and progressing to **Statistical Inference**, **Regression**, and **Causal Inference**.

These lecture notes serve as supplementary material for learning, study, and reference.

---

## Course Structure

The planned structure is:

```text
Module 0 — Mathematical Prerequisites
Module 1 — Probability
Module 2 — Statistical Inference
Module 3 — Regression
Module 4 — Causal Inference
```
